# Каталог камер

Справочник — статический JSON в бандле. Появится отдельным шагом итерации 0: типы и схемы
valibot, `cameras.json` и `films.json`, тест, валидирующий каталог схемой. В рантайме каталог
не валидируется — он меняется только вместе с кодом и проверен CI.

## Версия каталога

В JSON хранится номер версии. При росте номера пользовательские камеры перечитывают спеки
по `specId`. Камеры, заведённые вручную, хранят свой слепок спеки и от каталога не зависят.

## Источники

У каждой модели в JSON указывается ссылка на источник. Спеки — факты из открытых спецификаций
производителей:

- Lomo'Instant Wide — технические характеристики
- Lomo'Instant Automat — технические характеристики
- Fujifilm Instax Mini 99 — спецификация
- Fujifilm Instax Wide 400 — спецификация
- Fujifilm Instax Mini 12 — спецификация
- Polaroid I-2 — характеристики при анонсе
